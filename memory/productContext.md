# Product Context

## Why this project exists

Personal task managers must be fast, low-friction, and private. Deadronostask aims to provide a simple, distraction-free task experience with realtime sync and small resource footprint.

## Problems solved

- Slow, bloated task apps
- Sync complexity
- Poor offline experience

## Users and UX goals

- Primary users: individuals who want a focused, efficient task tracker
- Key UX goals: minimal onboarding, clear affordances for task CRUD, accessible controls, keyboard-first interactions

## Acceptance criteria (high level)

- Users can create, edit, delete tasks and projects reliably
- Sync works across devices and recovers gracefully from offline
- Application passes automated test suite for main flows
